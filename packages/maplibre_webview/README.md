# maplibre_webview

WebView implementation for [maplibre](https://pub.dev/packages/maplibre).
This package is published as a pre-release because it depends on a
pre-release of `flutter_inappwebview`, so add the pre-release version
explicitly:

```bash
flutter pub add maplibre_webview:^0.3.7-beta.1
```

See the [setup guide](https://flutter-maplibre.pages.dev/docs/getting-started/setup/#setup-windows-and-macos)
for the platform specific setup.
